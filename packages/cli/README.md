# halo-ds

The command line tool for the [Halo design system](https://halo-design-system.github.io/Halo-design-system/).

```bash
npx halo-ds init
```

Installs Halo in your React app (Vite or Next.js), sets light, dark or system mode, and can apply your brand colour.

## Commands

| Command | What it does |
| --- | --- |
| `npx halo-ds init` | Install Halo, pick the mode and a brand colour |
| `npx halo-ds theme "#2F6BFF"` | Make Halo your brand colour, in light and dark |
| `npx halo-ds docs` | List every component |
| `npx halo-ds docs badge` | When to use a component, how to import it, and its do's and don'ts |
| `npx halo-ds mcp` | The MCP server for AI assistants. Add it to your tool's settings: https://halo-design-system.github.io/Halo-design-system/docs/ai |

Run `npx halo-ds --help` for every option. Full docs: https://halo-design-system.github.io/Halo-design-system/docs/cli
