# Figma Community listing

What to paste into Figma's publish form. The icon is `icon.png` (128 by 128) and the cover is `cover.png` (1920 by 1080), both in this folder.

## Name

Halo UI

## Tagline

Every Halo component, ready to place in any Figma file.

## Description

Halo is a free, open-source design system: a Figma library and React components built from the same tokens, in light and dark.

This plugin lists all 56 Halo components as cards, A to Z, with a search box. Click a card to place the component on the canvas. Select a frame first to place it inside the frame.

It works in any file. The first time you place a component, the plugin adds Halo's variables and text styles, builds the component on a "Halo components" page and places an instance. Components you place again reuse it.

The window follows Figma's light or dark theme.

Website and React docs: https://halodesignsystem.dev
Source code (MIT): https://github.com/Halo-design-system/Halo-design-system
