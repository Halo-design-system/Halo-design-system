# Theming

Halo is built so you can make it look like your brand. Every colour, font, space and corner comes from a token, in Figma and in code, so changing the tokens changes everything built with them.

There are two ways to do it.

## Quick rebrand in code

Load your own CSS after Halo's, and set the brand variables on `:root`. Set them again for dark mode, where brand colours are usually lighter.

```css
/* brand.css, anywhere in your app: your values always win over Halo's */
:root,
[data-theme='light'] {
  --halo-button-primary: #2f6bff;           /* primary buttons */
  --halo-button-primary-hover: #1f5fe0;
  --halo-button-primary-pressed: #1f5fe0;
  --halo-fill-brand: #2f6bff;               /* checkboxes, switches, sliders, progress, tab underline */
  --halo-fill-brand-hover: #1f5fe0;
  --halo-surface-brand: #eaf1ff;            /* soft brand backgrounds, selected rows */
  --halo-surface-brand-secondary: #c9daff;  /* icon circles, tinted areas */
  --halo-surface-brand-contrast: #1f5fe0;   /* selected page, active outlines */
  --halo-surface-brand-heavy-contrast: #123c99;
  --halo-text-brand: #1a4cc2;               /* brand text */
  --halo-text-link: #2f6bff;                /* Link buttons */
  --halo-border-contrast: #2f6bff;          /* hovered fields */
  --halo-border-focus: #c9daff;             /* focus rings */
  --halo-illustration-accent: #d6e4ff;      /* illustration highlights */
  --halo-illustration-accent-strong: #6e95f0;
}

[data-theme='dark'] {
  --halo-button-primary: #4d8bff;
  --halo-fill-brand: #4d8bff;
  --halo-surface-brand: #10275c;
  --halo-surface-brand-secondary: #183a85;
  --halo-text-brand: #a9c4ff;
  --halo-text-link: #a9c4ff;
  --halo-border-focus: #183a85;
  --halo-illustration-accent: #183a85;
  --halo-illustration-accent-strong: #a9c4ff;
}
```

If you also support `data-theme="system"`, repeat the dark block inside `@media (prefers-color-scheme: dark) { [data-theme='system'] { … } }`.

### Fonts

Load your font, then point the two font variables at it:

```css
:root {
  --halo-font-family-body: 'Inter', system-ui, sans-serif;   /* paragraphs, inputs, tables */
  --halo-font-family-label: 'Inter', system-ui, sans-serif;  /* buttons, labels, headings */
}
```

### Corners and spacing

The same works for shape. For example, square off every button, field and pill by changing the full-round radius:

```css
:root {
  --halo-radius-xl: 8px;
}
```

Every variable is listed under **Foundations** in the sidebar. Change the semantic ones (like `--halo-button-primary`), not the raw scales (like `--halo-color-purple-300`): the semantic ones are what components read, and they also work when set on a single section of a page, as in the example above.

## Full rebrand from Figma

Use this when designers and developers should share one source of truth.

1. **Copy the Figma file.** Duplicate the Halo library into your team and publish it as your own library.
2. **Change the variables.** In the Primitives collection, replace the purple scale with your brand colour's shades, from lightest (0) to darkest (900). In the Typography collection, set the font family variables. Components, illustrations and docs pages update straight away, because they are all bound to variables.
3. **Check Semantic.** The Semantic collection maps meanings (button, surface, text, border) to the scales, with a Light and a Dark mode. Adjust any mapping that needs it, for example a darker shade for text so it stays readable.
4. **Export.** In Figma, open **Local variables**, then right-click each collection (Primitives, Semantic, Typography) and choose **Export modes**. You get one file per mode, like `Semantic/Light.tokens.json`.
5. **Rebuild the tokens.** In your fork of this repository, replace the files in `packages/tokens/figma/<Collection>/` and run:

   ```bash
   pnpm build:tokens
   ```

   This regenerates `tokens.css` with your values. Publish it under your own package name, or keep it in your app.

Awards keep their own bright colours on purpose and are not linked to the brand tokens. Illustrations follow the `--halo-illustration-*` variables.
